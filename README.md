# 绞一纹 · 金谷轩数字绞胎工坊

全国高校商业精英挑战赛品牌策划竞赛数字营销赛道 H5 项目。目前完成 01 入坊至 07「我的这一纹」交互 MVP，包含烧成成品、稳定体验纹号、PNG 纹卡、本地作品存档。公网持续部署说明见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 本地运行

使用 Node.js 22.12+（当前环境为 24）和 pnpm。在本项目目录运行：

```sh
pnpm install
pnpm dev
```

访问 `http://localhost:5173`。开发服务监听 `0.0.0.0`，同一 Wi-Fi 下的手机可访问终端显示的 Network 地址；若系统询问防火墙权限，只允许所需的专用网络。手机不能使用电脑的 localhost 地址。

当前 Codex 环境已提供 pnpm。如外部终端没有 pnpm，可先使用已安装的 npm 执行 `npm install -g pnpm`，再运行以上命令。

## 编译与静态部署

```sh
pnpm build
pnpm preview
```

`build` 先做 TypeScript 检查，再生成 `dist/`。将 `dist/` 的内容上传至支持 HTTPS 的普通静态托管平台即可；无需 Node 服务、数据库或后端。使用域名根目录资源路径和 hash 路由，支持 `#/clay` 直接访问、刷新。获得正式 HTTPS 地址后即可生成二维码供手机访问。本阶段未发布网站或生成正式二维码。

## 第二阶段：择泥与共享制作状态

- 四种数字视觉占位泥料（胎白、焦褐、墨黑、赤陶）均在 `src/config/clays.ts` 中配置，不代表金谷轩实际生产材料。
- `ClayLump.tsx` 使用原创不规则 SVG、颗粒、凹凸与明暗；点击后以约 620 毫秒动画移动至中央制泥台，两块泥保持分离。
- 选择一块提示「第一色已入泥。」；两块提示「两泥已备，可以起绞。」并激活主按钮。第三种被拒绝并提示先取消一种，可点候选泥团或中央泥团移出。
- `GuideCharacter.tsx` 默认只显示轻量提示，无角色图片。取得正式透明角色素材后，通过可选 `image` 属性传入。
- 选择两种泥料后，主按钮进入「03 绞胎」，沿用同一份颜色快照。

`src/state/WorkshopProvider.tsx` 在应用根部提供统一状态；所有后续制作页面应通过 `useWorkshop()` 读取同一份数据。`WorkshopState` 包括：

| 字段 | 当前含义 |
| --- | --- |
| `selectedClays` | 最多两个有序泥料快照，保存 id、名称、十六进制颜色和说明 |
| `gesturePath` | 归一化拖动轨迹，含压力、时间、接触编号和输入类型 |
| `twistCount` / `foldCount` / `pressCount` | 绞、折、长按压合次数 |
| `directionChanges` / `reverseFoldCount` / `crossingCount` | 有效转向、回拉与轨迹交叉次数 |
| `interactionProgress` | 不显示在界面上的制作进度，控制三段视觉演进 |
| `generatedPattern` | 03 完成时保存的同源纹样 PNG 与算法版本 |
| `finalPattern` | 04 切开完成后保存的同源矢量截面参数、两色和来源标识 |
| `vesselType` | 预留器型，初始为 null |
| `experienceId` | 本次制作唯一标识，刷新后保留 |

状态保存在当前浏览器的 localStorage（键为 `jiaoyiwen.workshop.v1`）。刷新保留泥料、顺序、颜色和制作标识；损坏或不兼容缓存安全恢复为空状态。存储不可用时仍可在本次打开期间选择泥料。不同域名、浏览器和设备各自保存，不做跨设备同步。

现已使用 schemaVersion 2，仍使用原存储键以迁移已有记录。旧 v1 择泥记录会保留颜色快照与 experienceId，并获得由该制作标识派生的固定种子；v2 恢复完整操作。不要在后续页面另建颜色随机值。校验脚本可在 Node.js 22.18+ / 当前 24 环境运行：

```sh
node --test tests/*.test.mjs
```

目前 25 项检查覆盖择泥、接触黏合、共同轮廓、局部压扁展宽、复杂度来源、顺序重放、1000 次拖动、输入边界、恢复和缓存迁移。未新增测试框架依赖。

第二阶段已通过 TypeScript 检查和生产构建；浏览器验证了首色入台、双泥就绪、第三种拦截、移出替换和刷新保留选择，控制台无警告或错误。在 375×812、390×844、430×932 实际内容视口下检查标题、制泥台、候选泥料与底部操作区，未发现横向滚动或操作区遮挡。尚未进行真实 iOS、Android 或微信内置浏览器测试。

## 第三阶段：Canvas 绞胎 MVP（渐生纹层精修）

第三阶段实现绞胎交互；现已接入下面的第四阶段开纹。

### 泥体先变化，色层跟随

- `engine.ts` 使用 57 个横向截面，初始为已经叠合的两块宽色层，中央较厚，边缘有轻微不规则起伏。不是预先绘制的密纹图片。
- 内部 `interactionProgress` 由拖动距离、转向、回拉、交叉、绞折与压合计算。0–30% 只保留宽色层；30–65% 逐步折入局部宽带；65–100% 才在操作较多区域加入较细的嵌套色层。宽层始终保留，进度不显示给用户。
- 每一层都保存上、下边界的材料坐标，初始附加层为空。新层继承当时已经变形的界面；之后每次操作继续推动原有边界，不按全局频率重新生成整幅纹理。
- `render.ts` 将材料坐标映射到同一泥体截面：横向拉伸时截面变窄，色带随之变细；压合时泥体横向展开，色层跟随展开；局部上下拉揉改变外轮廓及内部界面。绘制使用 Canvas 路径与共同裁切，不给每条色带添加独立阴影。
- 顶面使用跟随截面的柔和体积明暗，浅侧缘延续相同色层，表面有轻微颗粒；不使用塑料高光。
- 长按约 420ms 压合一次，移动超过 8px 或取消接触会取消尚未触发的长按。后台保留轻绞最多 5 次、折合最多 3 次的限制；页面只保留弱化的文字控件。

### 页面收敛

已删除右上角预览框和全部可见次数。副标题为「顺着手，让泥慢慢相遇。」。第一次明显融合后，「纹，从泥里生出来了。」仅短暂显示约 1 秒。初始没有底部按钮；达到最低操作阈值后，「看看里面的纹 →」以约 800ms 淡入。减少动态效果设置下直接显示。

### 保存与重放

统一状态保存两色快照、固定种子、有序 `operationLog`、手势轨迹、绞折/压合/转向/回拉/交叉次数及 `interactionProgress`。压合记录包含位置和强度。拖动约每 450ms 保存一次，松手、页面隐藏、辅助动作立即保存。

当前算法版本为 4。同一版本使用 `replay(interactionSeed, operationLog)` 重建泥体与所有材料边界，完成时保存 384×384 PNG 和版本。旧操作记录保留，旧版本 PNG 不直接复用。刷新是继续已保存制作；从择泥更换颜色后才开始新的宽色层过程。

### 验证与限制

- `pnpm build` 通过 TypeScript 和生产构建；`node --test tests/*.test.mjs` 共 20 项通过，含三个阶段的层数、局部细层范围、材料边界随形变移动、1000 次拖动后保持体量、重放与缓存恢复。
- `tests/browser-input.html` 经实际页面控件运行合成 touch Pointer Events，验证初始简纹、连续回拉、长按、无预览/数字、按钮渐显、一次性提示、390×844 / 375×812 / 430×932 无溢出，以及保存、刷新与返回。
- `tests/fusion-visual.html` 用固定种子和连续操作展示对比；`tests/mobile-review.html` 嵌入 390×844 生产预览（需 `pnpm preview --port 5174`）。测试页面不进入生产构建。
- 单指二维几何近似，无真实体积守恒、任意翻转、撕裂或撤销。只按需绘制，Canvas DPR 最高 2，记录上限 6000 段，不增加第三方依赖。
- 浏览器手机视口和合成触摸不能替代真机。真实 iOS / Android / 微信的触感、系统手势与设备性能仍待手机验收。

## 第四阶段：04 开纹

`RevealPage.tsx`、`features/reveal/`、`config/reveal.ts` 与 `styles/reveal.css` 分别管理页面、确定性截面与输入/绘制、文案时序和移动端样式。

- 从 03「看看里面的纹」进入。先呈现横放的复合泥坯外表和少量层纹；完整切面尚未绘制。中央细线引导从上向下划过。
- `CutGesture` 检查起点、终点、垂直距离、路径方向和横向偏离。反向、短划、横划、远离中心及取消接触不触发；首次划错只给一次短暂提示。使用 Pointer Events，支持鼠标与触摸；工作台禁止默认滚动。
- 动画约 1800ms：先形成细缝，再缓慢移开两半，同时让切面从侧缘逐步转向视线。无粒子、发光、爆炸、奖励或音频。系统减少动态效果时缩短运动。
- 完整截面出现后保持安静 800ms，随后显示「你的纹，出现了。」；再隔 500ms 显示「没有第二道完全相同。」；最后淡入「让它成为一件器物」。
- 轻触切面切换 1 / 1.85 倍，双指支持 1–2.4 倍，放大后可拖动。Canvas 按设备像素比（最高 3）重绘矢量路径，无低分辨率贴图放大。键盘聚焦工作台后按 ↓ 切开；完成后 Enter / Space 放大、方向键移动、Escape 还原。

### 数据来源与确定性

`createFinalPattern` 必须收到有效的 03 `generatedPattern`，校验种子、算法版本和操作数量。`gesturePath` 逐点与操作日志核对，`twistCount` / `foldCount` 与重放结果核对。两色直接使用 `selectedClays` 快照，不在 04 随机配色或生成新种子。

03 保存的 PNG 用于确认来源，不直接拉伸它。引擎从固定 `interactionSeed` 与有序 `operationLog` 重建同一泥体和色层边界，04 将这些边界作正视切面的二维展开。这里是有来源约束的几何展示，不是真实三维体积切片模拟；前面操作很少时，最终纹层也会比较简洁。

`finalPattern` 在动画完成时写入共享制作状态，包含：版本、`sourceKey`、两种颜色、固定种子、完整材料模型及手势点数/绞折次数/03 快照版本等来源信息。没有依赖临时 DOM。后续器物、成品和纹卡应直接消费该对象，并可调用 `drawPatternFace` 在任意清晰度重绘。

刷新及未修改的往返保留已打开的截面，不强制重复切割。回到 03 继续操作、更换泥色时会清除不再对应的新旧结果；恢复缓存时重新核验来源，损坏或过期数据不会直接展示。

- 05、06、07 共用同一 Canvas、Three.js Scene、Camera 和 Mesh，保留烧成材质、器型、纹样和朝向；支持旋转查看。
- 体验纹号根据首次创建日期与固定种子生成并保存到 `experienceId`，旧 UUID 迁移时保留 `legacyExperienceId`，不会改写种子或纹样。日期存入 `createdAt`，刷新保持一致。纹号不是企业产品编号或官方溯源码。
- `features/collection/card.ts` 用现有渲染器导出器物，再独立绘制 1080×1440 纹卡；实际生成 PNG 并提供下载与长按保存图片。

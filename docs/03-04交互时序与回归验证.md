# 03→04 真实 H5 交互优化与验收

日期：2026-10-17。分支：feat/competition-media。没有推送 main 或部署生产。

## 范围与依据

上一轮 9.57 秒视频来自仓库之外的独立预览，它自动调用动画，结束后才更新04标题，不能证明生产路由和手势有效。
本轮修改当前 React 应用：TwistPage → RevealPage → VesselPage。生产原本已有主动划切，本轮保留并强化入口、中断与显示时序。

## 时序

1. 03点击完成，保存原有 generatedPattern，单次进入04；揉拉和辅助动画未结束时不允许离开。
2. 04标题立即出现，650ms完成观察视图转换。前半段绘制同一 finalPattern.model 的03视图，后半段绘制切割示意视图，以边缘转向连接，不交叉叠印不同泥坯。
3. 转换期间不能划切。转换后等待有效向下划切，键盘向下箭头保留无障碍替代操作。
4. 切口0–260ms，分离200–850ms，转正850–1500ms，显纹1500–1900ms。
5. 结果出现后安静600ms；1000ms第二句，1400ms下一步入口。
6. 后台时间不推进切割和结果文案；失焦清理未完成接触。切割中离开取消回调，不保存未完成结果。已完成作品刷新直接恢复。

## 复现

先启动项目：pnpm dev。在隔离浏览器上下文运行，不使用用户现有存储。

提供已有Playwright模块路径 PLAYWRIGHT_MODULE（未设置时尝试项目安装的playwright）、BROWSER_EXECUTABLE、REVEAL_OUTPUT（建议仓库之外）后执行：

    node scripts/verify-reveal-flow.mjs

H5_URL可指向本地开发服务，默认127.0.0.1:5173。脚本不安装依赖。frames/frames.txt保存实际浏览器帧时间，可用已有ffmpeg转换：

    ffmpeg -f concat -safe 0 -i frames/frames.txt -vf fps=30 -c:v libx264 -crf 17 -pix_fmt yuv420p -movflags +faststart -an result.mp4
